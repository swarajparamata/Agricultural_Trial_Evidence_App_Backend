# Agricultural trial sample data

All products, records, and results in these files are fictional.

Files
- trials_a.csv and trials_b.csv contain trial records in different formats.
- Four text reports contain further trial information.

Reference information
- Harvest Plus, HarvestPlus, and HARVESTPLUS refer to the same product.
- Root Boost, RootBoost, and ROOTBOOST refer to the same product.
- FR means France, DE means Germany, and ES means Spain.
- Potato and potatoes refer to the same crop.
- 1 t/ha equals 1000 kg/ha.
